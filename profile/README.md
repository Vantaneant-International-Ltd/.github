## VNTA Group

Vantanéant International. A quiet holding company. We build and operate a small
number of houses, the tooling that runs them, and selected client work.

Ireland. studio@vnta.xyz . [vnta.xyz](https://vnta.xyz)

### How this org is organised

Every repository sits in exactly one bucket. The bucket decides what a repo is
for, who owns it, whether it is public, and which files it must carry.

- **Infrastructure.** Shared tooling and the context layer that runs the group.
  Private by default.
- **Houses.** The brands we own and operate: VNTA (parent), Eirvox, Vendr,
  Maison Seul.
- **Client.** Work built and operated for an external owner. Always private.
- **Personal.** Experiments. Kept out of group work.

### The rules

Naming, required files, branching, visibility, and archiving are defined once, in
**[org-standards](https://github.com/Vantaneant-International-Ltd/org-standards)**.
That repo is canonical. If anything here disagrees with org-standards,
org-standards wins.

This `.github` repo holds only the pieces GitHub applies for us automatically:
this profile page, the default issue and pull request templates, and the reusable
CI workflows other repos call.
